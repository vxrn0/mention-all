# Политика безопасности

[English version](../SECURITY.md)

## Поддерживаемые версии

**Используйте только последнюю версию.** Поддерживается только ассет с
меткой "Latest" на странице https://github.com/vxrn0/mention-all/releases/latest.

| Версия | Поддерживается |
| --- | --- |
| Последний релиз на GitHub | Да |
| Любой более старый тег или ассет | Нет |

Старые версии остаются в репозитории только для истории. Они могут не
работать с актуальными версиями клиентов, не тестируются и не получают
исправлений, включая исправления уязвимостей. Перед сообщением о проблеме
обновитесь до последней версии.

## Надёжные сборки

- Скачивайте `.plugin` только со страницы релизов GitHub или из телеграм-канала
  `@vxrn0` (https://t.me/vxrn0).
- Проверяйте ассет по `SHA256SUMS` из того же релиза.
- Смотрите на разрешения при установке: `messages.send` и `network` нужны, чтобы
  получить список участников и отправить упоминания; `hooks` включает
  подсказку `@all` и локальное отображение `@all`. Разрешение `hooks` даёт
  широкие возможности — плагин, запрашивающий большее, должен вызывать подозрение.
- Плагин обновляется только когда вы ставите новый файл: сам он код не скачивает.

## Сообщение об уязвимости

Предпочтительно: приватный "Report a vulnerability" во вкладке Security
репозитория. Также можно написать на `vxrn@tutamail.com` или в Telegram
[@vxrn0](https://t.me/vxrn0).

Не публикуйте детали эксплойта в открытом issue. Укажите версию плагина,
клиент и его версию, шаги воспроизведения и соответствующий лог. Это небольшой
побочный проект: ответы даются на лучших усилиях, без гарантии срока;
подтверждённые проблемы исправляются в последней версии.
